# E7 — Rendering method review and ownership

The source review covers CanvasManager and RenderManager in full, including the
unchanged paths. Acceptance measurements and final verification are tracked in
[V5-E7-STATUS](V5-E7-STATUS.md); this inventory alone does not close the gate.
The accepted E6 manager/grid/draw traversal remains the simulation baseline.

## CanvasManager and helpers

| Methods/state                                                                    | Decision and invariant                                                                                                                                                                                                                                                                                                                                                                                                            |
| -------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| getTransferredCanvas, isHtmlCanvasElement                                        | Retain actual HTML/Offscreen surface discrimination, support/transfer errors, and the Symbol.for transfer association. This is a browser resource cache across independently loaded engine copies, not per-engine configuration. Transfer once; Engine's separate ownership symbol rejects concurrent consumers and releases the owner on failed setup/destroy.                                                                   |
| getEffectiveColorSpace, getEffectiveContextAttributes                            | Retain effective context attribute readback rather than assuming a requested P3/float16 context was obtained. Precision and gamut remain separate. Reads are setup/media-event work, not per-particle conversions.                                                                                                                                                                                                                |
| setStyle                                                                         | Retain the union of old/new CSS keys, explicit deletion, and existing important-priority restoration policy. It runs on setup/repair/fullscreen, so do not introduce a cache that misses caller CSS mutations.                                                                                                                                                                                                                    |
| constructor, fullScreen, size, standardSize                                      | Retain manager-owned logical/bitmap dimensions and per-container renderer. Caller canvases remain caller-owned. Fullscreen follows resolved options, not cached construction-time input.                                                                                                                                                                                                                                          |
| loadCanvas                                                                       | Retain caller DOM/offscreen surfaces, source style snapshot, generated-canvas handling and initial retina sizing. Do not substitute a newly allocated canvas on HDR changes: export and presentation use the original surface. Engine orchestrates ownership and failed-load cleanup.                                                                                                                                             |
| init, safeMutationObserver                                                       | Disconnect the previous observer before replacement. Ignore callbacks from retired observer identities after stop/re-init, including already captured callbacks. Initialization order remains resize/style → observer → plugin lists → context/background/listeners → renderer.                                                                                                                                                   |
| initBackground                                                                   | Retain CSS background color/image/position/repeat/size; canonical color conversion uses effective output capabilities. No manual RGB conversion or new output cache is introduced.                                                                                                                                                                                                                                                |
| initPlugins, applyResizePlugins                                                  | Retain registration order and fresh resize-hook membership on init/refresh. Look up methods on each invocation. Preserve resize notifications rather than coalescing them behind a new scheduler.                                                                                                                                                                                                                                 |
| resize, windowResize                                                             | Retain unchanged-size early return, DOM geometry and retina bitmap dimensions, density/options/plugin ordering and conditional refresh. A zero previous axis now gets a neutral factor; other axes scale proportionally. Explicit OffscreenCanvas dimensions are initialized from its source; windowResize remains a DOM-only operation. Existing debounced event generation/cancellation remains EventListeners' responsibility. |
| getZoomCenter, setZoom                                                           | Retain logical-coordinate center (bitmap / pixel ratio) and caller-supplied center semantics. The zoom plugin owns transforms and its save/restore; manager setters do not redraw or mutate particle state.                                                                                                                                                                                                                       |
| initContext                                                                      | Retain float16/P3 → P3 SDR → sRGB fallback. Never replace the presentation/export surface. Existing contexts keep their original attributes; capability output follows effective attributes. Context absence remains a no-op renderer path rather than a fabricated successful context.                                                                                                                                           |
| initHdrListeners, removeHdrListeners                                             | Retain both gamut/range queries and shared change handler. Increment a manager-local generation on retirement, so a captured old handler cannot refresh a stopped/replacement scene. Remove only this manager's listeners.                                                                                                                                                                                                        |
| initStyle, repairStyle, resetOriginalStyle, setFullScreenStyle, setPointerEvents | Retain options/fullscreen/style restoration, pointer-event ownership and temporarily disconnected observation during repair. External style edits remain observable.                                                                                                                                                                                                                                                              |
| stop, destroy                                                                    | Retain observer/media cleanup, generated DOM removal and caller CSS restoration. Renderer destroy now drops its context so an old renderer cannot draw/clear a canvas reused by a new owner. Stop retains the context for restart.                                                                                                                                                                                                |

## RenderManager and helpers

| Methods/state                                                                                                 | Decision and invariant                                                                                                                                                                                                                                                                                                                                                     |
| ------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| constructor, settings, setContextSettings, setContext                                                         | Retain manager-local hook lists, context/settings, warnings, color scratch data and transform scratch data. setContext resets the default composite mode; external hooks may subsequently change it.                                                                                                                                                                       |
| canvasClear, clear, getLayerPlugins                                                                           | Retain dedicated clear-hook precedence, first true short circuit, plain-clear option, and per-invocation identity Set. Preserve live method lookup and per-layer membership lookup, including initPlugins inside a callback and late-added clear methods. Keep reentrant clears independent.                                                                               |
| numeric drawLayers                                                                                            | Enumerate the fixed numeric enum once at module scope; reuse the same order in clear/initPlugins/destroy. No duplicated numeric layer definition and no per-frame reverse enum names/array. Public plugin layer metadata does not assign hooks; its documentation is corrected accordingly.                                                                                |
| draw                                                                                                          | Retain callback return values and no-context no-op. It deliberately exposes the real context; internal style/composite caches cannot assume state survives callbacks. Destroyed renderers no longer retain a drawable context.                                                                                                                                             |
| drawParticles                                                                                                 | Preserve clear → simulation update → background element → background callback → mask → setup → plugin content → particles → cleanup. Background draw failures warn once; no general color/shape batching or hook reorder. External options/hook mutation keeps its existing observation points.                                                                            |
| drawParticle                                                                                                  | Retain guards, color/opacity/depth computations, setup/pre/post/cleanup hooks and ordinary reusable scratch objects. Nested draws receive independent color/transform scratch objects and save/restore the outer context. The normal path adds no per-particle scratch object or context save/restore. A finally block restores the nested-state flag on success or error. |
| drawParticlePlugins, drawParticlePlugin                                                                       | Retain hook order, live method lookup, callback arguments and no-context behavior. Do not replace specialized hook arrays with a universal scheduler.                                                                                                                                                                                                                      |
| applyPreDrawUpdaters, applyPostDrawUpdaters, setTransformValue                                                | Retain instance identity, updater order, color overrides and multiplicative transform semantics. Private-state browser fixtures cover init/update/draw within each cycle and after redraw/refresh.                                                                                                                                                                         |
| drawParticle (private), drawShape, drawShapeBeforeDraw, drawShapeAfterDraw, drawBeforeEffect, drawAfterEffect | Retain transform/style/line-width assignments, plugin transforms, effect/shape order, paths, fill/stroke and distinct escaping IShapeDrawData/position objects. Always reset the particle transform when a drawer/effect/transform hook throws. Nested context restore preserves outer draw state.                                                                         |
| getPluginParticleColors                                                                                       | Retain first defined fill/stroke overrides and canonical normalization with manager-local result scratch space. Values are destructured before setup/draw callbacks; ordinary drawing does not allocate an extra result tuple.                                                                                                                                             |
| init, initPlugins, initPluginsArray, initLayerPlugin, initUpdaters                                            | Retain hook-based membership in all applicable layers, per-particle arrays and actual container updater instances. Rebuild membership on refresh/redraw integration; do not instantiate a separate updater for rendering.                                                                                                                                                  |
| paint, paintBase                                                                                              | Retain mask paint handling/first-true setup fallback and full-canvas fill. Preserve clear versus paint distinctions and plugin compositing.                                                                                                                                                                                                                                |
| paintImage                                                                                                    | Preserve image/opacity/sizing and restore globalAlpha in finally even when the source cannot be drawn. Errors still propagate; cleanup does not replace the original failure.                                                                                                                                                                                              |
| isSupportedElement, resolveBackgroundElement, updateBackgroundElement, warnOnce                               | Retain canvas/video/image/offscreen discrimination, guarded selectors, nonfatal missing/invalid sources, fixed warning keys and explicit option-change resolution. No new asynchronous asset owner is introduced.                                                                                                                                                          |
| stop, destroy                                                                                                 | Stop clears while retaining the restartable context. Destroy clears first, then drops context, background/warnings and every hook/updater array. No context can be used after destruction through draw/stop.                                                                                                                                                               |

## Adjacent contracts and ownership inventory

| Resource/contract                                    | Owner and verification                                                                                                                                                                                                                                                                                                            |
| ---------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| DOM canvas placeholder / transferred OffscreenCanvas | Caller (supplied) or CanvasManager (generated). Engine owns only the active lease. The transfer association belongs to the browser surface and intentionally survives destroy. Browser tests cover independent engines, conflict, same-surface reuse and one transfer.                                                            |
| Explicit OffscreenCanvas / worker                    | Caller supplies and presents/transfers the exact surface. No DOM canvas or DOM event receiver is fabricated. The full All worker fixture exposed unguarded document/HTMLElement access in interactivity; these accesses now guard DOM availability. DOM event semantics are unchanged.                                            |
| Context, styles, background source                   | Renderer/context lifecycle is container-local. Supplied drawable sources remain external. Background failures are nonfatal and warning-deduplicated. Detached renderers cannot redraw a replacement surface.                                                                                                                      |
| Observer and media subscriptions                     | CanvasManager, with explicit stop/removal and stale callback rejection. Resize scheduling remains EventListeners; visibility/interactivity receivers are DOM-only.                                                                                                                                                                |
| Shape/effect/updater instances and particle state    | Container/ParticlesManager retain their existing initialization/reset ownership. Canvas uses the same updater objects. E6 bucket ID order and stable draw cohort are preserved.                                                                                                                                                   |
| Depth range and bucket order                         | Options rejects nonfinite/nonpositive zLayers with RangeError before allocation or depth division. Positive fractional ranges preserve their existing semantics (bucket count floors to at least one); no new practical cap or sparse representation is introduced. Finite particle depths retain descending bucket and ID order. |
| Image/video export                                   | DOM export reads the original DOM surface. Explicit OffscreenCanvas image export keeps the existing absent-result fallback. Video cancellation/track cleanup remains the export plugin's responsibility and existing regression coverage. The canvas migration does not create a second export surface.                           |
| Late assets and callbacks                            | Background resolution/drawing is synchronous and guarded; no async background owner is created here. Existing image/GIF/Poisson and export cancellation regressions remain in the full suite. E8 still owns independent complete extension coverage; it does not defer these E7 canvas checks.                                    |

## R1–R4 alternatives

- R1: retain a fresh per-call Set. The measured reentrant pooled-set variant is
  slower than numeric enumeration with a fresh Set in every tested case and
  requires extra cleanup/lifetime machinery. Reject it. Reject a precompiled
  clear list: late hook lookup and callback-triggered layer replacement are
  observable, with deterministic characterization tests.
- R2: adopt one numeric enum sequence. Compare actual compiled clear methods,
  then verify whole-scene runtime/allocations and delivered bytes. The isolated
  microbenchmark is not an FPS claim.
- R3: retain per-particle context assignments and distinct public draw records.
  External drawer mutation and retained draw-data tests demonstrate why general
  style caching/pooling would change behavior without a new invalidation/API
  contract. Keep current draw order and avoid batching across blending/depth
  boundaries. Restrict new temporary scratch/save work to nested draws.
- R4: retain setup CSS union and existing resize notification policy. Unchanged
  dimensions already skip resize; further caching across mutable options, CSS,
  retina/context changes or external hooks has no safe invalidation contract.
  Fix stale callbacks and zero-size recovery, and measure setup/resize/teardown
  separately in the existing M6/M8 extended harness.

No package extraction, dynamic import, mandatory capability dependency, public
export removal, or alternate rendering backend is introduced. M1/M2/minimal/lazy
consumer graph measurements verify the retained boundaries. Complete composition
and all supported bundler/browser policies remain E9/E10 responsibilities.
