# Deprecated public APIs and migration paths

Inventory from the checked-in TypeScript sources and Stencil loader declaration
on 2026-11-24. E9 recorded migration paths. E10 removed the Confetti and Ribbons
aliases and four deprecated color style helpers after migrating active consumers
and documentation. Remaining source deprecations are confined to the retained PJS
compatibility API and the Stencil v4 loader.

| API                                                  | Supported migration                                                                                      | Notes                                                                                                                                                                                                                                                                                                                                               |
| ---------------------------------------------------- | -------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Engine `getStyleFromRgb`, `getStyleFromHsl`          | Use engine `getStyleFromOklch` for engine output                                                         | Removed in E10; use the engine's output-aware OKLCH formatter.                                                                                                                                                                                                                                                                                      |
| Engine `colorMix`                                    | Use engine `colorMixOklch`                                                                               | The old RGB-returning API was removed in E5; this helper returns canonical OKLCH.                                                                                                                                                                                                                                                                   |
| HSV plugin `getStyleFromHsv`                         | Use engine `getStyleFromOklch` on canonical color input                                                  | Removed in E10; convert HSV to OKLCH and use the engine formatter.                                                                                                                                                                                                                                                                                  |
| OKLCH plugin `getStyleFromOklch`                     | Use engine `getStyleFromOklch`                                                                           | Engine helper maps a copy to the active canvas gamut.                                                                                                                                                                                                                                                                                               |
| Confetti `origin`                                    | Use `position` in percent coordinates                                                                    | Removed in E10; normalized 0–1 coordinates must be converted to percent.                                                                                                                                                                                                                                                                            |
| Confetti `particleCount`                             | Use `count`                                                                                              | Removed in E10 after active examples were migrated.                                                                                                                                                                                                                                                                                                 |
| Ribbons `origin` and `position`                      | Use `positionX` in percent                                                                               | Removed in E10; `origin.x` was normalized and `position.x` was percent.                                                                                                                                                                                                                                                                             |
| Ribbons `particleCount`                              | Use `count`                                                                                              | Removed in E10 after active consumers and docs were migrated.                                                                                                                                                                                                                                                                                       |
| PJS `IParticlesJSOptions` and its legacy option keys | Use the tsParticles option format                                                                        | See the PJS migration guide. The PJS package remains an opt-in compatibility surface.                                                                                                                                                                                                                                                               |
| PJS `particlesJS(tagId, options)`                    | Use the selected engine's `load({ id: tagId, options })`                                                 | Use the modern option format.                                                                                                                                                                                                                                                                                                                       |
| PJS `particlesJS.load(tagId, url, callback)`         | Use the selected engine's `load({ id: tagId, url })`                                                     | Handle the returned promise directly.                                                                                                                                                                                                                                                                                                               |
| PJS `pJSDom`                                         | Use the selected engine's `dom` collection                                                               | Avoid the global/implicit singleton shape from particles.js.                                                                                                                                                                                                                                                                                        |
| PJS `setOnClickHandler`                              | Use the selected engine's `setOnClickHandler`                                                            | Register on the engine that owns the scene.                                                                                                                                                                                                                                                                                                         |
| Stencil loader `applyPolyfills()`                    | Remove the call; await `defineCustomElements()` when component registration must finish before hydration | Stencil v5 removed the export because its ES2022 browser target no longer needs the legacy polyfills. See the [Stencil v5 upgrade guide](https://stenciljs.com/docs/v5/upgrading-to-stencil-5#code-that-uses-your-library) and [SSR registration guidance](https://stenciljs.com/docs/v5/ssr#-define-the-components-before-the-framework-hydrates). |

Remaining source annotations are in
`bundles/pjs/src/VincentGarreau/{IParticlesJS,particles}.ts` and
`wrappers/stencil/loader/index.d.ts`. Confetti, Ribbons, and color formatters no
longer expose the deprecated APIs listed above. The Stencil wrapper still uses
Stencil v4, so `applyPolyfills()` remains in its published loader until the
wrapper upgrades to Stencil v5.
