# E5 color representation inventory

Audit snapshot: 2026-11-22. This inventory follows non-test TypeScript
references to `IRgb`, `IRgba`, `IHsl`, and `IHsla` across the workspace, then
records the raw pixel-source boundaries. It classifies the remaining source,
compatibility and output artifacts after the E5 migration. Source conversion,
native Skia pixel, CanvasMask, emitter-canvas and unit-output regressions pass.
Current mapped-output browser pixels pass eight Chrome 157 cases, including
alpha, canonical source immutability and float16 HDR. Particle/performance
profiles now include matched E4/pre/post-cache matrices with identical scenes.
The bounded link cache improves M4 draw and allocation costs; residual M4 draw
budgets and remaining option/state/cache cost comparisons stay open. The user waived bundle growth
as an E5 blocker.

## Open classifications

- All entries above are input compatibility, temporary conversion, output
  compatibility, or pixel/source API boundaries; this symbol-based inventory
  found no unresolved `IRgb`/`IHsl` semantic runtime state in those files.
- The RGB-returning `colorMix()` was removed before E10; use
  `colorMixOklch()` with canonical input. E10 also removed the deprecated
  engine RGB/HSL style helpers and HSV/OKLCH plugin-local CSS formatters. Direct
  users should resolve inputs to OKLCH and use the engine output formatter.
- Canvas mask, emitter canvas sampling, and GIF source boundaries have no
  complete end-to-end browser regressions listed above. The emitter source
  pixel conversion helper is unit-covered; real sRGB/P3/HDR pixel output still
  requires browser evidence listed in `V5-E5-STATUS.md`.
- A follow-up workspace search for structurally typed RGB and color-bearing
  state found no additional persistent semantic RGB/HSL runtime fields beyond
  the typed entries above. Remaining structural surfaces are the documented
  PJS input facade, source-pixel buffers/assets, conversion helpers and test
  fixtures. Dynamic canvas-mask/emitter callbacks are boolean pixel filters;
  they receive source-space metadata but do not return or persist semantic
  colors. Browser-only config examples use these predicates only for alpha or
  pixel selection. The callback/example source review is complete; the current
  mapped-output browser fixture remains an evidence gate.
