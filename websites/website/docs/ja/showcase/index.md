# Showcase

tsParticles で他の人が作ったものを紹介します。アニメーション背景からインタラクティブな紙吹雪や花火まで、プロジェクト、デモ、コミュニティの作品を集めました。

## 公式インタラクティブデモ

コピーして応用できるすぐに使えるレシピを試せます:

- [すべてのデモを見る](/ja/demos/) — カテゴリ別エフェクト（ambient、紙吹雪、花火、雪など）
- [Playground を開く](/ja/playground/) — JSON 設定をライブ編集
- [プリセットカタログ](/ja/demos/presets) — 既成のアニメーションシーン
- [シェイプカタログ](/ja/demos/shapes) — 利用可能なすべてのパーティクル形状
- [パレットカタログ](/ja/demos/palettes) — カラープリセット
