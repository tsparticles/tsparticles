# Showcase

看看其他人用 tsParticles 构建了什么。从动画背景到交互式纸屑和烟花，这里汇集了项目、演示和社区作品。

## 官方交互式演示

试用可直接复制并调整的现成配方：

- [浏览所有演示](/zh/demos/) — 按类别划分的效果（ambient、纸屑、烟花、雪等）
- [打开 Playground](/zh/playground/) — 实时编辑 JSON 配置
- [预设目录](/zh/demos/presets) — 预构建的动画场景
- [形状目录](/zh/demos/shapes) — 所有可用的粒子形状
- [调色板目录](/zh/demos/palettes) — 颜色预设
