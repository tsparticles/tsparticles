# Showcase

Descubre lo que otros han creado con tsParticles. Desde fondos animados hasta confeti y fuegos artificiales interactivos, aquí tienes una colección de proyectos, demos y trabajos de la comunidad.

## Demos interactivas oficiales

Prueba recetas listas para usar que puedes copiar y adaptar:

- [Explorar todas las demos](/es/demos/) — efectos por categoría (ambient, confeti, fuegos artificiales, nieve, etc.)
- [Abrir el Playground](/es/playground/) — edita configuraciones JSON en vivo
- [Catálogo de presets](/es/demos/presets) — escenas animadas predefinidas
- [Catálogo de formas](/es/demos/shapes) — todas las formas de partículas disponibles
