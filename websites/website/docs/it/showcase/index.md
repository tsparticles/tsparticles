# Vetrina

Scopri cosa hanno costruito gli altri con tsParticles. Dagli sfondi animati ai coriandoli interattivi e ai fuochi d'artificio, ecco una raccolta di progetti, demo e lavori della community.

## Demo interattive ufficiali

Prova le ricette pronte all'uso che puoi copiare e adattare:

- [Sfoglia tutte le demo](/it/demos/) — effetti per categoria (ambient, coriandoli, fuochi d'artificio, neve, ecc.)
- [Apri il Playground](/it/playground/) — modifica configurazioni JSON dal vivo
- [Catalogo preimpostazioni](/it/demos/presets) — scene animate predefinite
- [Catalogo forme](/it/demos/shapes) — tutte le forme particellari disponibili
- [Catalogo tavolozze](/it/demos/palettes) — preimpostazioni di colore
